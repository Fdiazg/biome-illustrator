# Registro de cambios

Formato de [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/). Mientras
el paquete esté en `0.x`, la API puede cambiar entre versiones menores.

## [0.1.0]

Primera versión pública (`ENGINE_VERSION = 3`).

- Siete sujetos: `flat`, `ink`, `line`, `grove`, `cumulus`, `dunes` y `meadow`.
- Tres formatos (`plate`, `wide`, `square`) y seis paletas.
- `renderIllustration`, `renderMotif` y `renderPiece`, con las piezas del
  jardín: sol, luna con fase, matas, margarita, piedra, mata, hoja grande,
  ciprés, árbol redondo, cerros, camino y farol.
- Opciones `colors: 'css'`, `displayWidth`, `growth` y `registration`.
- Entradas `biome-illustrator`, `biome-illustrator/core` y `biome-illustrator/react`.
